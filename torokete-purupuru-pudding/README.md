# とろけて！ぷるぷるプリン

Build: `20261007-play-modes1`。smooth7 を復元点として、四つの遊びを常設しました。

- **もちもち**：最初の画面。カスタードだけの自由遊び。同じ大きさを深く押し合わせて一段大きく、二本指で伸ばして一段小さく。時間・目標・自動回収なし。最大段階同士はカラメルのきらきらに。
- **びよーん**：深く押し合わせると境目のないひとつの塊に。片側を持ち上げても離れた端が床に残って伸び、放すと数秒かけて丸く戻ります。二本指で伸ばしても切れません。
- **この子をつくろう**：3色の目標遊び。時間なし。
- **2分チャレンジ**：3色の目標遊び。2分間。

「遊びを選ぶ」で切り替えます。各モードのぷりんと進み具合は、開いている間それぞれ保持します。メニューを開いている時と他のモードにいる時は時間が止まります。ページを再読み込みすると最初からです。「やり直す」は今のモードだけを戻します。

スマホは一本指でつかんでなで、二本指で両側を引っぱります。PCの「もちもち」・目標遊びでは Shift＋クリックで分裂。「びよーん」は Shift＋ドラッグで反対側をつかんだまま伸ばせます。音は初期OFF。追加は12個まで、「びよーん」は追加した材料12個分までです。

## ローカル実行

追加インストール不要。Node.js があれば `node tools/serve.mjs 4173` を実行し、表示されたローカルURLを開きます。

`node --test tests/*.test.mjs` で物理・合体・分裂・自由遊び・塊の伸縮の検証を実行できます。`node tools/build-single-file.mjs` は画像を含む単一HTMLを作ります。単一HTMLはダブルクリックでも遊べます。

初期のぷりん・透過顔素材は既存作品の素材を再利用しています。顔の輪郭をフェードでぼかさず、伸びた時の泣き顔や、なでた反応を残しました。スコアやゲームオーバーを自由遊びへ追加していません。
