# とろけて！ぷるぷるプリン

ぷるぷるのプリンを手で押し合わせて育てたり、二本指で引き伸ばして分けたりする、スマホ向けの触って遊ぶブラウザゲームです。

## 遊ぶ

https://tsubakinu-cpu.github.io/purupuru-pudding/torokete-purupuru-pudding/

## 操作

- 同じ色・同じ大きさの二個を、片方をつかんで深く押し合わせると合体します。
- 大きいプリンを二本指で左右へ引き伸ばすと、同じ色の二個へ分裂します。
- PCでは大きいプリンを `Shift` を押しながらクリックすると分裂できます。
- 最大段階の二個は色が違っていても合わせられ、きらきらへ弾けます。
- 右上の目標を順番に作ると、くるんと飛んでお届けされます。
- 通常モードは時間制限なし。2分チャレンジでは届けた数と最高コンボを記録します。

音は初期状態でオフです。スコアやゲームオーバーを気にせず、合体・分裂と柔らかな触り心地を楽しめます。
