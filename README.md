# ぷるぷるぷりん

プリンをつつく、つかむ、落とす、重ねるためのスマホ向け柔体玩具です。点数・勝敗・タイマーはありません。

## GitHub Pages

このリポジトリはビルド不要です。`index.html` に画像・スタイル・ゲームコードを内包しています。

1. このフォルダの `index.html` と `README.md` をリポジトリ直下へ置く
2. GitHub の **Settings → Pages** を開く
3. **Deploy from a branch** を選び、公開ブランチの `/ (root)` を指定する

## 操作

- 短くタップ: 触れた場所がへこみ、ゆっくり戻る
- ドラッグして離す: 持ち上げて落とす
- `＋ プリン`: 最大7個まで追加
- `やり直す`: 3個に戻す
- `音 OFF`: 押した時だけ音を有効にする

スマホの縦横回転、複数ポインタ、pointer cancel、ページ非表示時の一時停止に対応しています。
