# とろけて！ぷるぷるプリン — smooth7

同じ色・同じ段階のプリンを手で深く押し合わせて合体させる、新作ブラウザゲームです。大きいプリンは二本指で十分に引き伸ばすと一段小さい同色の二個に分かれます。最大段階の二個は色違いでも押し合わせられ、きらきらしたカラメル粒を散らして弾けます。

公開ページ: https://tsubakinu-cpu.github.io/purupuru-pudding/torokete-purupuru-pudding/

元ゲーム: https://tsubakinu-cpu.github.io/purupuru-pudding/

- 3色・3段階。追加ボタンで12個まで追加できます。
- 軽い接触や積み重ねでは合体せず、途中で離すと元に戻ります。
- PCではShiftを押しながら掴むと二本目の支点を置いて分裂を試せます。
- タップ・なで・床のつぶれ・引っ張り時の泣き顔・分裂時の驚き顔を備えています。既存の透過顔素材を使っています。
- 既存の目標と時間モードは今回の滑らかさ修正で変更していません。

ビルド: `20261006-smooth7`。独立した作業コピーで開発しました。元ゲームと過去の作業コピーは変更していません。

混雑時の大きなドラッグを小刻みに解き、接触の法線が逆向きに飛ぶ問題と、15fpsの横押しで接触補正が掴んだプリンを後退させる問題を修正しました。接触時の輪郭の柔らかさ、合体時の深い押し込み、空いた場所での指追従を保っています。非常に重い環境のフレーム落ちや、小さな接触補正をすべてなくすものではありません。

開発にはNode.js 20以上を使います。追加パッケージのインストールは不要です。

```powershell
node tools/serve.mjs 4173
node --test
node tools/build-single-file.mjs
```

Chromeのタッチ入力、PC操作、390×844・320×568・844×390画面で検証しています。実機iPhone/Safariは未確認です。
